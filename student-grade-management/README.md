# Student Grade Management System.

A command-line Student Grade Mangement System written in Python that allows the user to manage student records. Users can add,view,update,search, and delete student information while validating the inputs to ensure data integrity.


## Features
- add student
- view all student
- search student by name
- update student grades
- delete student records
- grade validation (0-100)
- name validation
- case insensitive search

## Technologies
- python3
- Dictionaries
- Lists
- Exception Handling
- Functions
